主題一：HTML 文件的超鏈結 (Hyperlinks)

對應教材：第六章 mvshtmlch06.ppt / 範例 6-1 ~ 6-9

1. 核心觀念：URL 結構與 7 大 Scheme（服務協定）

在 HTML 中負責超鏈結的是一組對稱性標籤 <a> ... </a>，最重要屬性為 href，其設定值為 URL（Uniform Resource Locator，一致資源定位器）：

<a href="scheme://host[:port]/path/filename"> 提示符號（可為文字字串或圖片） </a>
  • scheme（協定/服務類型，必背 7 種）：
    1. http：超本文傳輸協定 (HyperText Transfer Protocol)，專供 Web Server 傳送 HTML 網頁至瀏覽器。
    2. file：連結至本地 (Local) 電腦上的檔案（例如光碟機或硬碟 file:///e|/chart-7/link-d.htm），不可用於需經過 Internet 網路的檔案擷取。
    3. ftp：檔案傳輸協定 (File Transfer Protocol)，用於 FTP 伺服器檔案上傳或下載（如 ftp://ftp.tku.edu.tw/ftp/incoming/）。
    4. mailto：電子郵件服務，點擊後會開啟寄信軟體寄給指定帳號（如 mailto:diy@mail.hpdiy.com.tw）。
    5. telnet：遠端登入服務。
    6. news：網路新聞討論群組。
    7. gopher：早期的選單式資訊檢索系統。
  • host：所連接電腦的 IP 位址 (IP Address) 或領域名稱 (Domain Name，如 www.nfu.edu.tw)。
  • port：連接至電腦中某伺服器的埠號。一般 Web Server 預設埠號為 80，若省略則以內定值 80 視之。
  • path 與 filename：被指定連接檔案的目錄路徑名稱與檔案名稱（如 /xml_family/index.html）。

2. 絕對路徑 vs. 相對路徑（為什麼強烈推薦相對路徑？）

比較項目 絕對路徑 (Absolute Path) 相對路徑 (Relative Path) ⭐ 強力推薦
定義 從頭寫出完整的協定、主機名稱、目錄與檔名，與目前正顯示中的網頁位置沒有任何關連。 只寫相對於「目前瀏覽器正顯示網頁所在目錄」的非完整路徑，瀏覽器會自動計算：目前路徑 + 相對路徑。
使用時機 要從目前網頁連往其它「非本站（外部網站）」時才使用。 瀏覽同一個 Web 網站內的所有網頁超鏈結皆應使用相對路徑。
最大優點 位址固定明確。 當網站要搬移到另一台 Server 伺服器時，只需將整個網站目錄 Copy 過去即可運作，不必修改任何一個超連結！

<html>
<head><meta charset="utf-8" /></head>

<body link="blue" vlink="green" alink="pink">

  • <body> 三個超連結顏色屬性：
    • link：超鏈結字串尚未被點選過的顏色。
    • vlink：超鏈結字串已被點選過的顏色。
    • alink：超鏈結字串被滑鼠按下時（按著不放、尚未放開）的顏色。
  • accesskey="英文字母"：設定於 <a> 內，字母不分大小寫；按下 Alt + 該字母 會直接聚焦 (Focus) 到該超鏈結。

  • align 屬性 5 種設定值（必考比較）：
    1. bottom（內定值/預設值）：文字的第一列與圖片的下方對齊。
    2. middle：文字的第一列與圖片的中間對齊。
    3. top：文字的第一列與圖片的上方對齊。
    4. left：圖片靠左邊顯示，多行文字從圖片的右邊上方處往下顯示（文繞圖）。
    5. right：圖片靠右邊顯示，多行文字從圖片的左邊上方處往下顯示（文繞圖）。
  • hspace vs. vspace：hspace="n" 代表 Horizontal Space（左、右水平方向與文字間的縫隙）；vspace="n" 代表 Vertical Space（上、下垂直方向與文字間的縫隙），單位皆為像素 (pixel)。

        <area shape="poly" coords="583,8,608,82,664,64,642,9" href="ce.html" alt="四邊形大樓">

    </map>

    <!-- 2. 在 <img> 加上 usemap 屬性關聯上方的 map 名稱 -->

🔥 地圖索引 (Image Map) 考試必背三要素
  1. 標籤結構：外層為 <map name="地圖名"> ... </map>，內層放多個 <area shape="..." coords="..." href="..." alt="...">，最後在圖片標籤加上 <img src="..." usemap="#地圖名">（簡報亦寫作 usemap="圖片名稱"）。
  2. 三種 shape 與 coords 數字個數：
    • shape="rect"（長方形）：4 個數字 "x1,y1,x2,y2" → 左上角 (x1,y1)、右下角 (x2,y2)。
    • shape="circle"（圓形）：3 個數字 "x1,y1,r" → 圓心 (x1,y1)、半徑 r (pixel)。
    • shape="poly"（多邊形）：2N 個數字 "x1,y1,x2,y2,x3,y3..." → 順時鐘或逆時鐘依序排列 N 個頂點座標（三角形 3 對共 6 個數字；六邊形 6 對共 12 個數字）。
