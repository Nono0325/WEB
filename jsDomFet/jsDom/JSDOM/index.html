課程重點精華整理

1. DOM (Document Object Model) 核心觀念與架構

  • 跨平台與語言獨立介面：DOM 讓程式（如 JavaScript）能動態讀取、走訪與修改 HTML 及 XML 文件之內容、結構與樣式。
  • 樹狀結構 (Tree Structure)：整份 XML 會被解析為一個層級節點樹（Document 根 -> 元素節點 -> 文字節點/屬性節點）。
  • 常見 Node Type 判定：
    • nodeType == 1：Element 元素節點（如 <book>, <title>）
    • nodeType == 2：Attribute 屬性節點
    • nodeType == 3：Text 文字節點（包含標籤間的空白與換行）
    • nodeType == 9：Document 文件節點
  • 常用走訪與屬性 API：
    • childNodes：取得所有子節點清單（包含空白換行之 Text 節點，因此遍歷時必須搭配 nodeType == 1 過濾）。
    • getElementsByTagName("標籤名")：直接依照標籤名稱搜尋符合之元素陣列。
    • getAttribute("屬性名")：讀取標籤內部屬性值（如 <book sales="Y"> 的 sales）。
    • textContent：直接取得該節點及其子節點的純文字內容。
    • firstChild, nextSibling, hasChildNodes()：節點間平移與檢查子節點。

2. Fetch API 與非同步 XML 解析模式

  • 現代標準非同步流程： 
    fetch('data.xml')
  .then(response => response.text()) // 1. 取得 XML 文字內容
  .then(str => (new window.DOMParser()).parseFromString(str, "text/xml")) // 2. 解析為 XML DOM 物件
  .then(xmlDom => {
      // 3. 使用 DOM API 操作 xmlDom
  })
  .catch(error => console.error(error));
  • 本地檔案限制：基於瀏覽器安全政策（CORS），透過 fetch 載入 XML 需置於網頁伺服器（如 Visual Studio 的 IIS Express、Live Server 或 Python http.server）下執行，避免 file:/// 協定的存取受限。

3. RSS 2.0 (Really Simple Syndication) 標準架構

  • 根本結構：根標籤為 <rss version="2.0">，內部僅允許包含一個 <channel> 節點。
  • Channel 必備三大子元素：<title> (頻道名稱)、<link> (網址)、<description> (頻道描述)。
  • Channel 常見選用元素：<language>、<pubDate>、<lastBuildDate>、<copyright>。
  • Item 資訊單元：<channel> 內部可包含多筆 <item>，至少需具備 <title> 或 <description> 其中之一，常用元素還包括 <link>、<pubDate>、<author>、<enclosure> (用於 Podcast 串接音檔)。
